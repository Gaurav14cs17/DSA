## 📐 Core Concept

**Dynamic Segment Tree:** Create nodes on-demand for sparse data.

**Use case:** Coordinate range up to $10^9$ but few actual values.

**Space:** $O(q \log C)$ where $q$ = operations, $C$ = coordinate range
